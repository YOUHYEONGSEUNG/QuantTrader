## 1. 개요

추세 봉(기본 3분봉)으로 추세를 **+1 상승 / 0 횡보 / −1 하락** 세 가지로 판단하고, 1분봉(진입 봉)에서 4가지 포지션 중 하나로 들어감. 의심은 진입이 아니라 **보유 중 일부청산 이벤트**이고, 시간대를 **장전(미국 개장 전) / 장후**로 나눔. 나스닥(MNQ)과 골드(MGC)에 같은 규칙을 쓰고 숫자는 종목 차트마다 설정값으로 둠.

**용어:** 진입 봉 = 전략을 올린 차트의 봉(1분봉), 추세 봉 = 추세를 판단하는 봉(3분 또는 10분). S = 느린 점수, F = 빠른 점수. dir = 방향 부호(매수 +1, 매도 −1).

## 2. 거울상 원칙 (4-0)

**모든 규칙은 매수로 한 번만 정의하고 매도는 거울상으로 계산함.** 트레이더 문서의 매수·매도 문구가 거울상이 아니면 매수 쪽을 기준으로 읽음. 코드도 방향 부호 `dir` 하나로 한 경로만 씀(매수·매도 함수를 따로 두지 않음). 밴드는 `Band(dir, n)`(n = 0 중심선), 비교는 `dir × (a − b) > 0` 꼴.

| 매수 | ↔ 매도 |
| --- | --- |
| 위 / 상방 / +N배 / 고가 | 아래 / 하방 / −N배 / 저가 |
| MACD 상승 전환, 골든크로스, %K 80 | MACD 하락 전환, 데드크로스, %K 20 |
| 최고가 − k·ATR (트레일링) | 최저가 + k·ATR |
| 종가 < 중기선 (청산) | 종가 > 중기선 |

## 3. 추세 판단 — `TQ_Regime` v3 (입력 = 추세 봉)

모든 이동평균·MACD·RSI는 추세 봉 기준. 진입 봉 지표는 `TQ_Signals`가 맡음.

### 3-1. 점수 항목 (각 +1 / 0 / −1)

| 층 | 항목 | +1 | −1 | 0 |
| --- | --- | --- | --- | --- |
| 느린 S | S1 가격 vs 중기선 | 종가 > SMA(Mid) | 종가 < SMA(Mid) | 같음 |
| | S2 구조 | `RegimeS2Mode` 1: SMA(Mid) > SMA(Slow) / 2: SMA(Slow)가 `RegimeSlopeBars`봉 전보다 높음 | 반대 | 같음 |
| | S3 MACD선 부호 | MACD선 > 0 | MACD선 < 0 | 0 |
| | S4 RSI (`RegimeUseRsi`) | RSI ≥ 50 + `RegimeRsiBand` | RSI ≤ 50 − 밴드 | 사이 |
| 빠른 F | F1 단기 가격 | 종가 > SMA(Fast) AND SMA(Fast) > 직전 봉 | 종가 < SMA(Fast) AND SMA(Fast) < 직전 봉 | 나머지 |
| | F2 MACD선 기울기 | MACD선이 `RegimeMacdSlopeBars`봉 연속 커짐 | 연속 작아짐 | 나머지 |

- S = S1+S2+S3(+S4): −4~+4 (S4를 끄면 −3~+3). F = F1+F2: −2~+2.
- 스토캐스틱·크로스·다이버전스는 추세 점수에 넣지 않음 (오실레이터는 타점용).

### 3-2. 상태 전이 (추세 봉 마감마다, 상승 기준이고 하락은 거울상)

| 지금 | 조건 | 다음 |
| --- | --- | --- |
| 상승추세 아님 | F ≥ `TrendStartFast`(1, 10/15에 2에서 내림) AND S ≥ `TrendStartSlow`(1, 같음) | 상승추세 (그 봉 = 추세 시작 봉) |
| 상승추세 | 하락추세 시작 조건 충족 | 바로 하락추세 |
| 상승추세 | S ≤ `TrendEndSlow`(0) | 횡보. `DirectReverse`(전략 `RegimeDirectReverse`, 기본 끔)를 켜면 그 봉에 F ≤ −2일 때 바로 하락추세 |
| 상승추세 | F ≤ −`SuspectFast`(2)가 처음 된 봉 | 상승추세 유지 + **하락의심 이벤트** 1회 |
| 상승추세 + 의심 중 | F ≥ 0 | 의심 해제 (이벤트 없음) |

- 의심은 해제된 뒤 다시 뜰 수 있음(해제 → 재발생마다 이벤트 1회). 추세가 바뀌면 의심은 지워짐.
- 확정 연속 봉 수는 두지 않음(10/14 데이터: 2봉 확정은 3분 늦어져 이긴 거래가 졌음). 흔들림은 시작(S ≥ 2)·종료(S ≤ 0) 기준 차이로 막음.
- 데이터 가드: 장기선, MACD(장기 + 시그널), RSI, 기울기 봉 수가 다 채워지기 전에는 `Regime = NaN`.
- 출력은 `docs/interface.md`.

### 3-3. 연속 점수 + 속도 판정 (v6 기본, `RegimeMode` 2, 사용자 제안 2026-10-15)

TQ_Regime의 정수 점수는 대회 구간의 60%가 |S| = 4로 꽉 차서 강약을 구분하지 못했다. 그래서 항목마다 −1~+1 연속값(소수 6자리)을 만들어 정도가 다르게 들어가게 하고, 점수가 바뀌는 속도를 판정에 쓴다. 전략이 TQ_Regime의 이평·MACD·RSI 출력과 추세 봉 ATR(14)로 계산한다(지표 파일은 그대로). **1분봉마다 지금 종가로 다시 계산한다** (이평·MACD·RSI는 직전에 마감된 추세 봉 값, a = 추세 봉 ATR).

| 항목 | 값 (매수 쪽 +) |
| --- | --- |
| 종가 − 중기선 | tanh((c − SMA20) / 1.5a) |
| 종가 − 단기선 | tanh((c − SMA6) / 0.75a) |
| 5봉 수익 | tanh((c − 종가[5]) / 2a) |
| 20봉 범위 안 위치 | 2 × (c − 20봉 최저) / (최고 − 최저) − 1 (c 포함) |
| 10점 회귀 기울기 | tanh(기울기 / 0.25a) (종가[9]~[1] + c) |
| 10점 효율비 | (c − 종가[10]) ÷ 변화의 합 |
| 중기 − 장기선 | tanh((SMA20 − SMA60) / 2a) |
| 장기선 기울기 | tanh((SMA60 − SMA60[5]) / 0.5a) |
| MACD선 | tanh(MACD / a) |
| MACD선 기울기 | tanh((MACD − MACD[2]) / 0.3a) |
| RSI | (RSI − 50) / 20, ±1로 자름 |

- **점수 C** = 11개 평균. **속도 V** = C − `ScoreVelBars`(6)개 1분봉 전 C.
- **판정 (1분봉마다, 하락은 거울상):** 상승 시작 = C ≥ `ScoreTrendOn`(0.2) 또는 (C ≥ 0 AND V ≥ `ScoreVelMin`(0.25)). 상승 끝 = C ≤ `ScoreTrendOff`(0). 상승 중 하락 시작 조건이면 바로 하락. 판정이 0이 아닌 값으로 바뀐 1분봉 = 추세 시작(E1).
- **진입·청산 기준의 S·F:** 연속 S = (종가−중기선) + (중기−장기선) + MACD선 + RSI (−4~+4), 연속 F = (종가−단기선) + MACD선 기울기 (−2~+2). 기준 코드는 그대로 두고 "S ≥ k" ⇔ "연속 S ≥ `ScoreScale`(0.9) × k"로 환산(E2 S ≥ 2 → 1.8, E3 S·F ≥ 1 → 0.9 …).
- **청산용 판정 (TREND_END·OPP_TREND, 횡보 포지션 반대 추세 청산):** 같은 점수 C로 따로 계산. 시작은 C ≥ `ScoreTrendOn`일 때만(속도 시작 없음), 상승 끝은 C ≤ `ScoreExitOff`(−0.1), C ≤ −`ScoreTrendOn`이면 바로 하락. 진입은 빠르게, 청산은 흔들림에 둔하게 (2026-10-15 사용자: 판정 흔들림을 줄여야 함). 고친 시뮬레이터(TREND_END 포함) 18일 E1+E3+B1: 같은 판정 7월 +11.8R / 10월 −4.6R −$7,976 → 청산용 판정 +11.8R / −3.1R −$5,145. 끝 기준만 −0.05~−0.15로 바꾸면 효과 없음(청산은 속도로 생긴 반대 판정 때문이었음).
- **E1 시점 (2026-10-15 사용자: 판정이 바뀐 봉은 이미 오른 뒤라 늦음):** E1 끔 7월 −2.6R, 중심선에서 1~1.5 ATR 넘으면 거르기 변화 없음(밴드 조건이 이미 거름), 되돌림 지정가(−0.5 ATR, 5·10분) 7월 −1.4 ~ −2.6R / 10월 +1.5R. 판정이 바뀐 봉에 바로 들어가는 지금 방식을 유지.
- **의심:** F(환산)가 추세 반대로 `SuspectFast`(2)에 처음 닿은 1분봉에 이벤트, F가 추세 쪽으로 0 이상이면 해제. 판정이 바뀌면 지움.
- 추세 봉 마감 줄(`N분봉 마감 …`)은 채점기 `--validate`를 위해 계속 TQ_Regime v3 값을 적는다. 진입 봉 줄에는 `점수C= 속도= 연속S= 연속F=`를 더 적는다.

## 4. 매매 규칙

### 4-1. 확정 원칙

1. 판단은 봉 마감 뒤. 예외: 밴드·ATR 지정가 익절과 손절 스탑은 봉 진행 중 체결.
2. 종목당 포지션 하나. 보유 중 새 진입 신호는 무시. 청산과 같은 봉에 반대 진입하지 않음.
3. **포지션은 4가지:** 추세 매수(TL), 추세 매도(TS), 횡보 매수(SL), 횡보 매도(SS). 역진입·역추세 진입은 없음.
4. **진입 뒤 추세가 바뀌면:**
   - 추세 포지션: 의심 이벤트 → 4-5 일부청산. 추세 종료(횡보) → 전량 청산(`TrendExitOnEnd`). 반대 추세 시작 → 항상 전량 청산.
   - 횡보 포지션: 반대 방향 추세 시작 → 전량 청산(`SideExitOnOppTrend`). 같은 방향 추세 시작 → 그대로 들고 감(횡보 규칙 유지).
   - **반대 추세 시작으로 전량 청산한 뒤에는 미보유가 된 다음 진입 봉부터 2봉 안에 그 추세의 E1을 허용함** (2026-10-15 사용자 결정. 그대로 두면 추세가 뒤집히는 봉에서 E1을 영영 놓침. 같은 봉 반대 진입 금지는 지킴).
5. 추세 판단은 직전에 마감된 추세 봉의 값을 씀. 추세 봉과 진입 봉이 같은 시각에 닫히면 실제로는 그 추세 봉 값을 바로 봄 (2026-10-15 v5 Playback 로그 4,407번 확인. 원래 1분 지연으로 적었고 시뮬레이터도 그렇게 계산했었음).

**4-2-1 E3 스탑 주문 진입 (v6, `E3StopEntry`, 2026-10-15 사용자 결정):** 진입 봉 마감에 시장가로 들어갈 경로가 없고, E3의 다른 조건(장후, `OrbEndTime` 전, 횟수, 다시 열림, S·F, 의심·F 반대 금지)은 맞는데 종가만 아직 박스 안이면, 박스 고가 + 1틱(매도는 저가 − 1틱)에 스탑 진입 주문을 걸어 닿는 순간 진입. 손절·수량·익절은 스탑 가격 기준으로 계산하고 체결되면 체결가로 다시 계산. 다음 봉에도 조건이 맞으면 같은 시그널명으로 다시 걸어 주문을 고치고(두 번 체결 방지), 안 걸면 NinjaTrader가 봉 끝에 취소. 한 방향만(관리형 주문은 미보유 때 한 방향 진입 주문이 살아 있으면 반대 진입을 무시, NT8 Managed Approach 문서), 둘 다면 종가에 가까운 쪽. 다른 경로가 시장가로 들어가면 먼저 취소. 공통 필터 (막히면 상태 상자·로그에 사유를 수치와 함께 남김):
- 진입 시간(4-7)과 장전 제한.
- 의심 중에는 그 추세 방향 신규 진입 안 함 (`BlockEntryWhileSuspect`). (10/15에 '가격 확인 뒤에만 막는' 완화를 넣었다가 반대 의심 중 E2 8건 3승 −$9,997로 v5에서 지웠음)
- **추세 진입은 빠른 점수가 반대면 안 함 (`TrendEntryNeedFast`, 기본 켬, 2026-10-15 사용자 결정):** E1·E2·E3 매수는 F ≥ 0, 매도는 F ≤ 0일 때만. 추세 판정은 늦어서(큰 움직임 시간의 약 28%를 반대 추세로 판정) 반전 초입에는 판정은 옛 방향인데 F는 이미 반대임.
- 횡보 방향 필터: S+F ≥ `SideBlockScore`(3)이면 SS 금지, ≤ −3이면 SL 금지.
- 재진입 제한: 횡보 포지션이 본절 전 손실 손절로 끝나면 그 대회 구간에서 같은 방향 횡보 진입 금지(`BlockSideAfterStop`). 추세 포지션은 제한하지 않음.
- **v6 기본값:** E1·E2·E3·E4 켬, B1 켬(박스 돌파). v5는 B1 끔, v4 브랜치는 B1만 켜고 E1~E4를 껐었음.
- 같은 봉에 여러 경로가 충족되면 E5 > E1 > E3 > B1 > E2 > E4 > E6, 진입은 1회 (v6에서 E5를 맨 앞에, E6는 맨 뒤). 같은 경로에 두 방향이 같이 충족되면 매수 먼저(구현 선택).
- 밴드 조건 없이 1분 T2만으로 추세 진입하는 경로는 없음.
- `SideT2Entry`를 끄면: `TQ_Signals.EntrySideLong`이 밴드 경로와 T2를 하나로 내므로, 직전 봉까지 밴드 대기가 없었는데 T2가 같이 나온 봉은 T2만의 신호로 보고 뺌.

### 4-3. 손절 (전 포지션 공통 식, 범위만 다름)

- **구조 손절:** 신호 봉 포함 최근 `SwingBars`(5)봉 저가 − 1틱. 거리를 신호 봉 1분 ATR(14) × [최소, 최대]로 자름. 추세 [`TrendStopMinAtr` 1.5, `TrendStopMaxAtr` 3.0], 횡보 [`SideStopMinAtr` 1.0, `SideStopMaxAtr` 2.0].
- 거리가 `StopMinTicks`(32틱 = MNQ 8pt)보다 작으면 그만큼 벌림 (장전 ATR이 절반이라 너무 좁아지는 것 방지).
- 신호 봉 종가로 먼저 걸고 체결되면 체결가로 다시 계산. 갭으로 이미 넘었으면 즉시 전량 청산(`GAP`).
- **이익 보호 본절 (`BreakevenAtR` 0.8, 2026-10-15 사용자 결정, v2와 같은 방식):** 1차 익절 전이라도 진입 뒤 최대 유리폭이 처음 손절 거리 × 0.8에 닿으면 진입 봉 마감에 손절을 평단으로. 4가지 포지션 모두(v2는 주력 진입을 뺐음). 근거: 7/15~30 9일 35건 시뮬레이션에서 0.8R이면 지던 4건이 본전, 이기던 1건(+$985)이 잘림, 합계 +$1,192. 0.5R은 이기던 5건을 잘랐음.
- 손절은 유리한 쪽으로만 움직임. 옮길 때 `BreakevenBufferTicks`(8) 안전 거리(가까우면 미뤘다가 봉 마감마다 재시도).

### 4-5. 의심 이벤트 처리 (추세 포지션 보유 중에만)

1. 추세 봉 `SuspectEvent`가 포지션 반대 방향으로 뜨면 확인 대기 시작 (`SuspectConfirmBars` 5 진입 봉, 이벤트를 본 봉 포함).
2. 대기 안에서 가격 확인: 진입 봉 종가가 직전 `SwingBars`봉(그 봉 제외) 저가 아래로 마감 (`SuspectNeedPrice`. 끄면 이벤트 즉시 실행).
3. 확인되면 남은 수량의 `SuspectExitPercent`(50%)를 시장가로 청산(`SUSPECT`). 그때 S ≤ `SuspectStrongSlow`(1)이면 `SuspectStrongExitPercent`(100%, `SUSPECT_STRONG`). 손절을 평단 이상으로(이익 중일 때만, 안전 거리 지킴).
   - **청산 수량은 먼 조각부터(마지막 → 2차 → 1차) 조각 단위로** 뺌 (2026-10-15 사용자 결정). 한 조각의 일부만 청산하면 그 조각에 걸린 익절·손절 주문 수량이 어떻게 되는지 NT8 문서에서 확인되지 않아 조각을 쪼개지 않음. 원하는 수량에 가장 가까워지는 곳까지 뺌(적어도 한 조각). 예: 30계약 9/9/12에서 50% → 마지막 12계약.
4. 대기 안에 가격 확인이 없거나 의심이 해제되면 아무것도 안 함.
5. 의심 하나당 한 번만 실행. 역진입 없음. 미보유면 4-2의 진입 차단만 적용.

### 4-8. 수량

- `EntryQuantity` 30 = 최대 계약 수, `MaxQuantity` 40(경고만).
- **위험 금액 수량 (`UseRiskSizing` 켬, `RiskPerTrade` $2,000, 2026-10-15 사용자 결정):** 계약 = `RiskPerTrade` × 구간 %(장전 50%, 최소 진입 보장 30%) ÷ (신호 봉 종가 기준 예상 손절 거리 × 계약당 가치), 최대는 `EntryQuantity` × 구간 %, 최소 1. 손절 거리가 짧으면 최대 계약, 길면 줄임. 체결가로 손절을 다시 계산해도 계약 수는 그대로. 근거: v3 21일 실제 1회 위험이 $252 ~ $6,324로 25배 차이. 시뮬레이션에서 $2,000이면 최대 1회 손실 −$4,564 → −$2,009, 합계는 줄어듦(큰 이익을 낸 E3도 손절 폭이 커서).
- **달린 뒤 진입 수량 줄이기 (v6, 2026-10-15):** 추세 진입(E5 제외) 신호 봉 종가가 밴드 중심선에서 진입 방향으로 `ExtendedEntryAtr`(2) × 1분 ATR보다 멀면 계약 × `ExtendedQtyPercent`(50%). 진입은 그대로(대회 최소 진입). 근거: v5 86건·v6 61건 Playback에서 중심선 거리 높은 ⅓(≥ 1.7 ATR)이 −2.3R / −5.3R, 낮은 ⅓이 +11.5R / +9.7R. 18일 시뮬레이션: 막으면(2 ATR) 진입 61 → 46건, 수량 절반이면 진입 그대로 7월 $34,852 → $34,289, 10월 $732 → $3,431.
- **1차 익절 전 트레일링은 넣지 않음 (2026-10-15 사용자 제안을 시험):** 최대 이익 0.3·0.5R 뒤 최고가 − 1.5·2 ATR, 중심선 − 0.5 ATR 모두 10월 +2.5R → −1.1 ~ −2.7R(되돌림 장에서 1차 전에 흔들고 가는 거래를 자름), 중심선 − 1 ATR은 변화 없음. 0.8R 이익 보호 본절(4-3)은 그대로.
- 단계 수량 = 진입 계약 × %를 내림, 마지막 조각이 나머지. 30계약 33/33 → 9 / 9 / 12. 장전 50%면 15계약 → 4 / 4 / 7.
- 의심 일부청산은 그때 남은 수량 기준(4-5).

### 4-9. 돌파 진입 B1 (v4에서 넣음, v5는 중립 돌파로 좁혀 기본 끔, v6는 박스 돌파로 바꿔 기본 켬)

> **v6 (2026-10-15):** 3번을 '박스에서 나오는 돌파'로 바꿨다. 효율비 = |직전 `BreakoutBoxBars`봉 처음 → 끝 종가 순변화| ÷ 봉마다 종가 변화의 합(지금 봉 제외). 0이면 왔다갔다(박스), 1이면 한 방향. 효율비 ≤ `BreakoutMaxEr`(0.25)일 때만 진입하고, 느린 점수는 보지 않음(`BreakoutMaxAbsSlow` 4). 최소 진입 보장 진입에는 적용하지 않음.
> - **근거 1 (돌파 112건, 7/16~31·10/5~14 연속 1분봉):** 직전 30봉 박스 지표별로 15봉 돌파의 30분 뒤 수익(돌파 방향, 1분 ATR 단위)을 봤음. 효율비 낮은 ⅓(≤ 0.15)은 7월 +2.15 / 10월 +1.64, 높은 ⅓(≥ 0.23)은 +1.13 / **−2.21**. 초피니스·폭/ATR·EMA 교차 횟수·ATR 확대·돌파 봉 길이·돌파 폭은 두 달 결과가 엇갈렸음. 이미 한쪽으로 달린 뒤의 돌파는 되돌림 장(10월)에서 실패함.
> - **근거 2 (`tq_entry_sim.py`식 재현, E1+E3+B1, 위험 $2,000):** v5 중립 돌파 7월 22건 +11.0R $19,760 / 10월 21건 −3.4R −$6,100 → 박스 돌파 0.25 29건 +13.0R $22,483 / 29건 −2.1R −$3,611. 0.2도 거의 같음. 진입이 늘면서 R도 나아졌음.
> - 같이 검토하고 넣지 않은 것: 추세 점수를 항목 11개 가중 연속값(−1~+1, 1분 갱신)으로 바꾸기 — 7월 +12.2R → +16.8R, 10월 −4.6R → +2.2R이었지만 켜는 기준을 0.05만 바꿔도 10월이 −4.5R ~ −0.1R로 흔들렸고, 회귀로 맞춘 가중치는 달마다 부호가 뒤집혔음(7월은 추세 지속, 10월은 짧은 가격이 되돌림 — 두 달 모두 맞은 항목은 중기−장기선 배열과 장기선 기울기뿐). 개장 직후(22:33~35) 수량 절반 — 실제 v5 10건 −$6,118이었지만 시뮬레이션은 7월 −$2,992 / 10월 +$1,479로 엇갈렸음.

> **v5:** 아래 3번이 'S > −`BreakoutBlockSlow`'에서 '\|S\| ≤ `BreakoutMaxAbsSlow`(1)'로 바뀌었고 기본 끔이다. 근거: S×F 칸별 시뮬레이션에서 중립 칸(\|S\| ≤ 1, F ±2)의 돌파만 두 종목 모두 이겼음(MNQ 16건 +8.5R, MGC 4~5건 +1.3~2.4R). 다만 v3에 더하면 v3 진입을 밀어내서 MNQ 25일 +11.6R $18,535 → +13.1R $16,885, MGC +2.0R → +1.3R(위험 $1,500 수량)이라 기본은 끔.

**왜:** 21일 분석(7/15~9/10)에서 추세 판정은 큰 움직임 시간의 약 28%를 반대 추세로 판정했고, 시작·끝 규칙을 바꿔도 속도와 흔들림을 맞바꿀 뿐이었음. 늦은 판정이 진입 방향을 정해서 반전 구간에 옛 방향 진입(의심 중 E2 8건 −$9,997)과 역방향 횡보 진입이 나왔음. 돈을 번 진입은 가격과 F가 방향을 정한 경우(E3)였음. 그래서 진입 방향은 가격 돌파와 F가 정하고, 느린 점수는 강한 반대 구조만 거름 (`docs/v4-design-draft.md`).

### 4-10. 개장 범위 돌파 E5 (v6, 2026-10-15 사용자 결정)

**왜:** 손실이 가장 많이 난 곳이 개장 직후 22:33~22:35 진입(v5·v6 Playback 14건 2승)이고, 돈을 꾸준히 번 곳은 박스 돌파(E3)였음. 개장 직후 몇 분은 범위를 재는 시간으로 쓰고 그 범위를 깨는 쪽을 따라감. 같이 검토한 되돌림(역추세) 17가지는 10월을 포함한 모든 달에서 손실이었음(가장 좋은 조합 10월 +1.3R, 합계 −5.6R 이하): 이 시간대는 10월에도 크게 한쪽으로 가는 움직임이 있어 반대로 들어가면 한 번에 크게 짐.

**규칙 (매수 기준, 매도는 거울상):**
1. 개장 범위 = `OpenTime`(22:30) 봉부터 `E5RangeMinutes`(5)개 진입 봉(22:30~22:34 봉)의 최고가·최저가.
2. 범위가 완성된 뒤(22:35 봉부터) `EntryEndTime`까지 진입 봉 종가 > 범위 고가 → 매수. 방향별 하루 한 번(최대 2번). 지표 발표·개장 전후 진입 금지는 그대로.
3. 손절 = 범위 중간 − 1틱. 거리를 신호 봉 1분 ATR × [`E5StopMinAtr` 1, `E5StopMaxAtr` 4]로 자르고 `StopMinTicks`보다 좁으면 벌림. 체결되면 체결가로 다시 계산.
4. 수량 = 위험 금액 수량(4-8), 구간 % 100. 조각 하나.
5. 익절 = 체결가 + `E5TargetR`(2) × 손절 거리 (지정가, 봉 진행 중). 최대 이익이 손절 거리 × `E5BreakevenR`(1)에 닿으면 손절을 평단으로 옮기고, 그 뒤 진입 뒤 최고가 − `TrailAtr`(2.5) × 1분 ATR로 따라감.
6. 추세 판정(TREND_END·OPP_TREND)·의심·T2 반대 신호로는 청산하지 않음. 종료 청산(23:27)은 공통.

| --- | --- | --- | --- | --- | --- |
| **5분** | 2R | +10.6R | −1.1R | +1.1R | 38건 +10.5R $20,036 |

### 4-11. 박스 장 대책: E6 되돌림 + 하루 손실 한도 (v6, 2026-10-15 사용자 결정: "10/7 같은 장날 대책 전략이 있어야 예선에서 안 떨어짐")

**왜:** 10/7은 대회 구간 내내 약 100pt(9 ATR) 안에서 움직였고, v6는 돌파형(B1 3건, E5 1건)이 모두 져서 −$1,885(v5 +$2,540). 28일을 하루 효율비로 3등분하면 박스 장 9일에서 가짜 돌파 되돌림 +6.1R / E5 −0.9R, 추세 장 9일에서 −0.9R / +5.3R — 서로 반대. 되돌림을 항상 켜면 −5.6R이라 박스 장을 알아본 뒤에만 켬.

**박스 장 감지:** 대회 구간 첫 봉(`ContestStartTime`) 종가부터 지금까지 효율비 = |지금 종가 − 첫 종가| ÷ 봉마다 종가 변화의 합. 첫 봉 뒤 60봉(22:30)이 지났고 효율비 ≤ 0.15면 박스 장.

**E6 규칙 (매수 기준, 매도는 거울상):** 박스 장, 장후, 진입 금지 구간이 아니고 `EntryEndTime` 전. 1~3봉 전 봉의 저가가 그 앞 30봉 최저가 아래였는데, 직전 봉 종가는 그 최저가 이하이고 지금 봉 종가가 위 → 매수. 손절 = 최근 4봉 최저가 − 0.25 ATR, 거리를 1분 ATR × [1, 2.5]로 자르고 `StopMinTicks`보다 좁으면 벌림. 한 조각, 익절 = 체결가 + 1R(지정가), 20봉이 지나면 시장가 전량(`TIME`). 본전 이동·트레일링·추세 판정·의심 청산 없음. 수량 = 위험 금액 수량.

**하루 손실 한도 (`DayLossLimitR` 1.5):** 이번 대회 구간에 끝난 거래 손익 합 ≤ −1.5 × `RiskPerTrade`(기본 −$3,000)이면 그 뒤 진입 수량 50%. 진입은 막지 않음(최소 진입).
