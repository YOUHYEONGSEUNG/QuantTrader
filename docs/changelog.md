### 레짐 전환을 빠르게 하는 실험 옵션 3개 추가 — 기본값은 지금 명세와 같은 동작 (spec 변경 아님)
- **문제:** 추세가 너무 늦게 바뀐다. 상승으로 돌아선 뒤에도 한동안 하락추세 규칙이 적용되고, 상승이 끝날 무렵에야 상승추세가 된다(차트 관찰).

- **옵션:** `Rule12Bars`(기본 5, 비교 구간), `Rule12PriceFilter`(기본 끔, 종가가 20선의 맞는 쪽일 때만 고점·저점 규칙 인정), `FastTrendBars`(기본 0, 종가가 N봉 연속 20선 위·아래면 바로 상승·하락추세. spec 3장의 1.3·2.3 자리).
- **판정 순서:** 이동평균 조건 → `FastTrendBars` → 고점·저점 규칙 → 횡보.
- **인터페이스 변경:** `TQ_Regime` 설정값 3개 추가. 전략 호출부도 같이 고쳤다.
- **근거와 한계:** 논리 검토로 만든 것이고 컴파일·백테스트 전이다. 어느 것이 실제로 나은지는 배경색과 백테스트로 비교해야 한다. 빨리 바뀌는 만큼 잘못 바뀌는 일도 늘어난다.

### 본절 손절이 재진입 제한을 거는 오류 수정 (spec 4장 — 명세 변경 아님, 구현을 명세에 맞춤)

### 오늘 넣은 규칙 세 가지를 원래 전략 취지에 맞게 좁힘 (spec 2장, 4장)
원래 전략은 "주력(5.1 상승추세 롱, 5.4 하락추세 숏)은 추세 방향으로 길게, 역추세는 극단에서만 짧게"다. 오늘 넣은 규칙 중 이 취지와 어긋나거나 의도치 않게 진입을 막는 것을 고쳤다.

- **T1 대기 봉 수 보정:** 실제 대기 봉 수 = N + (MACD 전환 확인 봉 수 − 1). 기본값이면 3 → 4봉.
  - 이유: 확인 봉 수를 2로 올리면서 MACD 전환이 t+1에는 확인될 수 없게 되어, 진입 기회가 3번에서 2번으로 줄었다. 확인 봉 수 4에서 진입이 0번이었던 것도 같은 원인이다. 의도는 잡음 제거였지 진입 창 축소가 아니었다.
  - 스토캐스틱·RSI 반전 신호도 같은 봉 수를 쓴다(이쪽은 기회가 1봉 늘어난다).
- **재진입 제한에서 주력 진입 제외:** 주력 진입(5.1, 5.4)의 손절은 제한을 걸지 않고, 주력 진입은 제한을 받지 않는다.

- **이익 보호 본절에서 주력 진입 제외:** 5.1, 5.4에는 적용하지 않는다.
  - 이유: −1배에서 사서 +2배·+3배까지 끌고 가는 거래라, 진입가를 되짚는 움직임에 본절로 끝나면 안 된다.
