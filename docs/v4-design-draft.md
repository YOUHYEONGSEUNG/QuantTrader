# 전략 구조 다시 설계 — 논의용 초안 (2026-10-15)

코드는 아직 바꾸지 않았다. v3(`v3-integrated`)의 21일 Playback 기록(7/15~9/10, MNQ, 63건)에서 나온 근거와 바꿀 방향을 정리한 것이다. 사람이 정해야 할 것은 5장.

## 1. 지금 구조

```
3분봉 느린 점수 S (이평 배열·MACD선 부호·RSI·가격 vs 중기선)
3분봉 빠른 점수 F (단기 가격·MACD선 기울기)
        │
        ▼
 추세 판정 +1 / 0 / −1  ── 시작: F와 S가 같은 봉에서 기준 이상
                         ── 끝: S가 0까지 내려옴 (S만 봄)
        │
        ├─ 진입 방향을 정함: 추세면 그 방향(E1·E2·E3), 횡보면 박스권 양쪽(E4)
        └─ F는 "의심"으로 일부청산에만 쓰임
```

## 2. 기록으로 확인한 문제

| 현상 | 근거 (21일) |
| --- | --- |
| 추세 판정이 늦음 | 큰 움직임 26개 동안 판정이 같은 방향 55%, 횡보 18%, **반대 27%**. 시작 기준을 F 1·S 1로 내려도 반대 28% |
| 늦은 이유는 "끝"에 있음 | 옛 추세는 S가 0까지 내려와야 끝남. S2(이평 배열)는 그 방향으로 바뀌기까지 평균 17분, 13번 중 5번은 끝까지 안 바뀜 |
| 반전은 거의 항상 횡보를 거침 | 반대 전환 27번 중 22번. S가 끝 기준(0)에 먼저 닿고 시작 기준은 그 위 |
| 판정을 빠르게 하면 흔들림 | F가 반대로 2면 추세를 끝내면 반대 판정 16%로 줄지만 추세 전환 28 → 49번, 횡보 판정 25% |
| 늦은 판정이 진입 방향을 정함 | 반대 의심 중 E2 8건 −$9,997. 반전 중간의 횡보 판정에서 E4가 거꾸로 진입 |
| 돈을 번 진입은 가격·F가 방향을 정한 것 | E3(장전 박스 돌파, F 같은 방향) 17건 +$14,223, 개장 직후 진입 27건 +$33,620 / 그 밖의 시간 36건 −$11,403 |
| 같은 진입도 달마다 갈림 | E3 7월 9건 +$28,288, 8·9월 8건 −$10,682 (개장 가짜 돌파, 손절 상한 ATR 3배인데도 1~3봉에 손절) |

결론: 이 지표들(3분봉 이평·MACD·RSI)로 만든 추세 판정은 큰 움직임의 1/4 이상을 늦게 본다. 판정 규칙을 고쳐서는 속도와 흔들림을 맞바꿀 뿐이다. 판정이 늦다는 걸 전제로, **진입 방향을 판정에 맡기지 않는** 구조가 필요하다.

## 3. 제안: 방향은 가격이 정하고, 느린 판정은 거르기만 한다

```
느린 판정 (지금 S, 그대로)  →  "이 방향으로는 들어가지 않음" 거르기만
                                 (예: S ≤ −2면 매수 금지, S ≥ +2면 매도 금지)
빠른 층 (F + 가격 구조)     →  진입 방향과 시점
   · 돌파: 최근 N분 고가·저가(또는 장전 박스) 밖으로 종가 마감 AND F가 그 방향
   · 눌림: 돌파 뒤 되돌림이 중심선 근처에서 멈추고 F가 다시 그 방향
청산                        →  지금 v3 그대로 (밴드 1·2차, 트레일링, 이익 보호 본절)
                                + F가 반대로 ±2면 일부청산 (지금 "의심"과 같은 자리)
```

- E3가 개장 때 한 번만 하던 일(가격이 범위를 깨고 F가 같은 쪽)을 장 내내 쓰는 형태다. 기준 범위는 "직전 N분 고가·저가"로 움직인다.
- 횡보 판정이 없어진다. 대신 범위 안(돌파 없음)에서는 E4 박스권 진입만 남기거나 아예 뺀다(E4 21일 15건 +$3,978, F를 거스른 11건 +$7,948 / 따라간 4건 −$3,970).
- 느린 판정은 강한 반대 구조에서만 막는다. 반전 초입(S가 아직 −1~−3)에서도 F와 가격이 돌면 매수할 수 있다.

## 4. 대안

| 안 | 내용 | 장점 | 걱정 |
| --- | --- | --- | --- |
| A. 위 제안 | 방향 = 가격 돌파 + F, S는 거르기 | 판정 지연과 진입이 분리됨. 이미 이긴 E3와 같은 원리 | 새 진입 규칙이라 검증이 처음부터 필요. 가짜 돌파(8월 개장) 대책 필요 |

| C. 추세 봉을 1분으로 | 같은 판정을 1분봉으로 | 빨라짐 | 흔들림이 더 커짐(3-1의 맞바꿈이 더 심해짐). 채점기로 먼저 확인 가능 |
